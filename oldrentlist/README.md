# Old Rental Listing Code

This folder contains the old product listing and rental marketplace code that has been moved out of the main application.

## What's Here

### App Routes
- `src/app/products/` - Product detail pages
- `src/app/shops/` - Shop listing and management pages
- `src/app/HomeClient.tsx` - Home page client component with product listings

### Components
- `src/components/ProductCard.tsx` - Product card component
- `src/components/ProductCardSkeleton.tsx` - Loading skeleton for products
- `src/components/ShopCard.tsx` - Shop card component
- `src/components/Filters.tsx` - Product filters component
- `src/components/ShopFilters.tsx` - Shop filters component
- `src/components/ContactModal.tsx` - Contact form modal

## Current Focus

The application now focuses on:
- **Vendor Registration & Login** - Rental owners can register and login
- **Subscription Management** - Vendors can subscribe to rentorent software
- **Profile Management** - Users can manage their profile and view subscriptions

## Note

These files are kept for reference but are not actively used in the current vendor-focused application.
